# Java Full Stack Internship - Task 1

## Project Title
Landing Page with Contact Form using HTML, CSS and Spring Boot

## Description

This project is developed as part of a Java Full Stack Internship.

It includes:
- Responsive Landing Page
- Contact Form
- Spring Boot Backend
- Form Submission
- Console Output
- Modern UI

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Java
- Spring Boot
- Maven

## Project Structure

Task1-LandingPage-ContactForm

frontend/
- index.html
- style.css
- script.js

backend/
- Spring Boot Project

## Features

- Responsive Design
- Navigation Bar
- Hero Section
- About Section
- Features Section
- Contact Form
- Spring Boot REST Controller
- Prints Submitted Data in Console

## How to Run

1. Open backend in IntelliJ IDEA or Eclipse.
2. Run TaskApplication.java.
3. Open frontend/index.html.
4. Fill the form.
5. Click Submit.
6. Check console output.
